# Marine Fleet Tracker Android

안드로이드폰/태블릿에서 선단 선박의 AIS 위치를 지도에 표시하기 위한 1차 앱 골격입니다.

## 핵심 목표

- 험한 환경에서도 앱이 최대한 죽지 않도록 설계
- AIS API 장애/인터넷 끊김 시 마지막 위치 또는 데모 위치 표시
- 우리회사 / 소형선망 / 대형선망 / 전체선망 화면 구분
- 나중에 위판실적, 조업기록, 전날 조업추정, 월별/연도별 통계로 확장 가능

## 현재 포함 기능

- OpenStreetMap 기반 지도 표시
- 선박 마커 표시
- 선박명, MMSI, 회사, 선단, 어업형태, 속력, 침로, 최종수신시간 표시
- 우리회사 / 소형선망 / 대형선망 / 전체선망 필터 버튼
- 수동 새로고침
- 15분 단위 백그라운드 동기화 골격
- 데모 AIS 데이터 fallback
- SharedPreferences 기반 마지막 위치 캐시
- 네트워크 오류, JSON 파싱 오류, 데이터 없음 방어

## 실제 AIS API 연결 위치

`app/src/main/java/com/bipiroo/marinefleettracker/data/AisClient.java`

기본값은 데모 데이터입니다. 실제 AIS 공급처 API를 쓰려면 `baseUrl`과 JSON 파싱 부분을 해당 공급처 형식에 맞게 수정하면 됩니다.

## Android Studio 실행 방법

1. Android Studio에서 이 폴더를 엽니다.
2. Gradle Sync를 실행합니다.
3. 안드로이드폰 또는 태블릿을 연결합니다.
4. `app` 실행.

## 주의

- Android WorkManager의 반복 작업은 보통 최소 15분 간격 제한이 있습니다.
- 10분 이하 갱신은 앱을 켜둔 상태의 수동/화면 갱신, 또는 포그라운드 서비스 확장이 필요합니다.
- AIS 위치는 “현재 위치”가 아니라 “최종 수신 위치”일 수 있으므로 앱에서 최종수신시간을 항상 표시합니다.
- 실제 항해 안전 판단용이 아니라 조업/선단 상황 파악 보조용으로 사용해야 합니다.
